# Wie ich KI auf dieser Seite nutze

## Regel

- **Text** (Blog, Portfolio, Über mich, Seiten-Texte, Übersetzungen): vom Autor geschrieben. Kein KI-Entwurf, keine KI-Überarbeitung, keine KI-Übersetzung.
- **Code** (App, Config, Gerüst, technische Docs): mit KI-Tools gebaut, vor allem [Cursor](https://cursor.com).

## Tools

- Cursor — Programmieren, Refactoring, Debugging, Scaffolding in diesem Repo
- Large Language Models über Cursor — nur für Code und technische Docs

## Was ich selbst mache

- Jedes Ich-Wort auf der Seite schreiben
- Entscheiden, was veröffentlicht wird
- Fakten, Links und Privatsphäre prüfen
- Verantwortung für Fehler und Ton übernehmen

## Privatsphäre

- Keine echten Firmen-, Kunden- oder Mitarbeiternamen in git
- Keine `.env`-Dateien, Zugangsdaten oder internen Systemdetails
- Inhalte so schreiben, als würde sie ein Fremder lesen
- KI-Assistenten folgen denselben Regeln über `.cursor/`

Vollständige Richtlinie: [AI-USAGE.md](https://github.com/werkscode/werkscode/blob/main/AI-USAGE.md)

## Commits

Wenn KI bei einem **Code**-Commit wesentlich geholfen hat:

```
Assisted-by: Cursor
```

Nicht für Commits, die nur selbst geschriebenen Text ändern.
